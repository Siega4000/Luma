# ffmpeg в составе Luma

В архиве с программой лежит `ffmpeg.exe` — отдельная свободная программа,
которую Luma использует для конвертации аудио и подготовки обложек.
Она не является частью Luma и распространяется по собственной лицензии.

## Лицензия

ffmpeg в этой сборке распространяется на условиях **GNU General Public
License версии 3** (GPL v3). Полный текст — в файле
`LICENSE-ffmpeg-GPLv3.txt` рядом с этим документом.

## Какая именно сборка

Версия ffmpeg указана в файле `FFMPEG-BUILD.txt` в этом же архиве —
он создаётся автоматически при сборке и содержит точный номер версии
и полный вывод `ffmpeg -version`.

Используется готовая сборка для Windows с сайта
https://www.gyan.dev/ffmpeg/builds/ (вариант «release essentials»).
Сборочные скрипты этой сборки опубликованы здесь:
https://github.com/GyanD/codexffmpeg

## Исходный код

GPL требует, чтобы вместе с программой был доступен её исходный код.

1. Исходный код ffmpeg той же версии прикладывается к каждому релизу
   Luma отдельным файлом — `ffmpeg-<версия>-source.tar.xz` на странице
   **Releases**.
2. Он же всегда доступен на официальном сайте проекта:
   https://ffmpeg.org/download.html и в архиве релизов
   https://ffmpeg.org/releases/
3. Если по какой-то причине файл недоступен, напишите по адресу,
   указанному в разделе «Контакты» ниже: мы бесплатно предоставим
   исходный код этой версии в течение трёх лет с момента получения
   вами данной сборки.

Изменения в исходный код ffmpeg не вносились: используется неизменённая
сборка стабильного релиза.

## Контакты

Запрос на получение исходного кода ffmpeg можно оставить здесь:
https://github.com/Siega4000/Luma/issues

## Если ffmpeg не нужен

Luma ищет ffmpeg и рядом с собой, и в системном `PATH`. Файл `ffmpeg.exe`
можно удалить из папки и установить ffmpeg отдельно:

```powershell
winget install Gyan.FFmpeg
```
